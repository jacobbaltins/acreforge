Data & privacy notice

AcreForge is an uncleared working name. This page describes the current prototype, not a complete commercial privacy policy or legal advice. Last updated November 2, 2026.

Do not enter sensitive information. This prototype is not designed for confidential property, financial, contact, or account data. Review any project before exporting or publishing it.

Project information saved in your browser

The planner and Home Builder save project content in local storage in the browser profile you are using. This can include project names, planning assumptions (including editable cost rates), objects, dimensions, notes, map coordinates, parcel geometry you import, drawn map overlays, user-supplied reference inventory locations, labels and filename, home layouts, and saved scenario comparison snapshots. The reference import is processed locally and its inventory is included in project backups but removed from public project export. Opening or moving the map still requests map tiles as described below. Theme and edit-mode preferences are also stored locally. The app does not provide cloud sync or user accounts in its interface. Anyone with access to this browser profile or device may be able to access its saved data.

The Reports page builds a concept-planning report in the browser. Printing or saving that report as a PDF uses your browser or operating-system print dialog; AcreForge does not upload it. If you choose to save or share a printed or exported file, the file may include project names, property assumptions, layout details, and checklist questions, so review it before sharing.

You can use the app's export and import tools to make or transfer project files. A user-supplied elevation grid CSV is read in the browser; its terrain grid and elevation range are saved with the project and may be included in backups and public exports. The re-importable terrain CSV is generated locally and contains relative grid coordinates and elevations, not original datum or provenance; its filename may include the project name. Exported files are not protected by this site; store and share them carefully. Clearing browser storage or using a different browser/profile may make local projects unavailable.

On a new browser profile, the start screen creates a blank project locally and remembers its dismissal in browser storage. A description entered there is transferred to the local rule-based planner and is saved as part of the project when you choose Generate plan; the welcome screen does not send it to an AI service.

Site Designer reference images are processed locally and their bytes are stored in this browser profile's IndexedDB, not uploaded. Placement and visibility are saved in project data, but backups do not contain the image bytes and public exports omit the underlay metadata. Re-import the original image when moving to another browser or device. Removing or replacing an image deletes its local copy; clearing site data also deletes it. Anyone with access to this browser profile or device may be able to access the image.

Reusable site-object presets are stored with the project and may contain user-entered names and cost settings. They are included in backups and public exports; review files before sharing.

Saved flat-plan views are stored with the project and include user-entered names, property-local center coordinates and zoom levels. Backups and public exports include these views; review files before sharing.

Map and network requests

The site is hosted by GitHub Pages. When your browser requests the site, GitHub and the network providers involved may process technical request information such as your IP address, browser, and requested files under their own policies. See GitHub's privacy statement.

When you open the terrain map, the browser requests map imagery from the U.S. Geological Survey and elevation tiles from AWS Terrain Tiles. Enabling slope, contour, or hillshade analysis requests up to 12 AWS Terrarium elevation tiles for the visible terrain extent per refresh; the browser samples those tiles locally. Choosing Import real elevation also requests AWS elevation tiles for the current property location or parcel. These services receive the network requests needed to return the map tiles, which can reveal the geographic area being viewed along with ordinary request metadata. See the USGS privacy policy and AWS privacy notice.

When you run Land Data or Analyze property, the browser sends up to nine sampled parcel coordinates—or one selected coordinate if no parcel is imported—to USGS EPQS, FEMA's National Flood Hazard Layer, and USDA Soil Data Access. Property analysis also requests AWS Terrain Tiles for local elevation sampling. These public services receive the coordinates or tile requests needed to return elevation, flood-zone, soil, and terrain data, along with ordinary network request metadata. The samples are sparse planning references, not a survey or determination. Buildability screening uses conceptual slope thresholds only; FEMA sample points are not shown as parcel-wide hazard boundaries. See the USGS privacy policy, FEMA privacy policy, USDA privacy statement, and AWS privacy notice.

The optional Mapped features control is off until you enable it. If enabled, the app sends the visible map bounds—not your full saved project—to the public OpenStreetMap Overpass API to request nearby mapped features. The bounds identify the small area currently displayed. See the OpenStreetMap Foundation privacy policy.

The Property page's Load mapped roads and Load mapped buildings controls separately send an approximate planning extent to the public Overpass API when you select each control. These lookups are optional, are not run until requested, and their temporary map references are not saved in your project. OpenStreetMap data may be incomplete and is not a verified inventory or legal access determination. See the OpenStreetMap Foundation privacy policy.

The Property Copilot command bar uses local rules in your browser and does not send prompts to a generative-AI service. Asking it to analyze a property starts the public-data requests described above.

Generated site layouts, utility-route estimates, and low/mid/high concept budgets are calculated locally from your prompt, project dimensions, editable cost assumptions, and any property-analysis context already available. The generator does not send prompts or layout contents to an AI service, verify legal road access or utility service, or provide engineering, permit, septic, or provider-cost determinations. Review generated placements and validate rates, routes, and septic assumptions before relying on them.

The app does not request device geolocation. It uses map coordinates that you select or provide through an import or map link. Map and public-data coverage can be incomplete or inaccurate.

Property-opportunity and build-zone suggestions are calculated in the browser from terrain and optional mapped-road context already available to the planner. They are heuristic references, not feasibility findings, and do not trigger separate data requests.

Public project exports

The separate public-export feature creates a project JSON file intended to be placed beside the site files on its host. If you do that, the file and its contents become available to people who can reach the published site. A view-only link is not access control. Check the file for names, coordinates, parcel details, notes, and other information you do not want to disclose before publishing.

Accounts, payments, and related services

The current site interface does not offer account sign-in, paid plans, or checkout. No payment link or fundraiser is presented here. However, Stripe webhook code remains in the deployment source and may be active only if separately configured with server-side settings. That configuration and any related provider records or logs have not been audited for this notice. The operator should verify the hosting configuration before making claims about whether Stripe or Supabase process any information.

In-app interest and feedback

The Settings → Feedback route and status-bar control build a draft only from a planned-feature interest choice, optional use-case selections, a feedback category, and an optional short note. Do not enter parcel addresses, coordinates, financial or contact details, or project files. The page reads the selected answers locally only to prepare the draft; it does not read project data, receive or save feedback, or send answers to AcreForge. No feedback inbox or analytics is configured. Its mailto: link has a blank recipient. Your mail client may open a draft, but you choose the recipient and press Send; if you send it, the recipient and your email provider handle its contents under their own policies. A copy option is also available. Copying places the text on your device clipboard; the app does not transmit it.

Analytics, advertising, and contact

The application source does not include a configured analytics or advertising script. This statement does not cover technical logs maintained by the site host or services listed above. This prototype currently does not publish a verified business identity, feedback inbox, or dedicated privacy-contact address. Do not submit sensitive information or expect this prototype to provide a formal data-request process.

Questions and future changes

This notice may need substantial revision before commercial use, especially if accounts, payments, analytics, cloud storage, support forms, or other data collection are added. A commercially launched service should identify its operator and provide an appropriate contact channel and complete, jurisdiction-aware privacy disclosures.
