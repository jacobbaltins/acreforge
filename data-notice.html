Data & privacy notice

AcreForge is an uncleared working name. This page describes the current prototype, not a complete commercial privacy policy or legal advice. Last updated October 24, 2026.

Do not enter sensitive information. This prototype is not designed for confidential property, financial, contact, or account data. Review any project before exporting or publishing it.

Project information saved in your browser

The planner and Home Builder save project content in local storage in the browser profile you are using. This can include project names, planning assumptions, objects, dimensions, notes, map coordinates, parcel geometry you import, drawn map overlays, and home layouts. Theme and edit-mode preferences are also stored locally. The app does not provide cloud sync or user accounts in its interface. Anyone with access to this browser profile or device may be able to access its saved data.

You can use the app's export and import tools to make or transfer project files. Exported files are not protected by this site; store and share them carefully. Clearing browser storage or using a different browser/profile may make local projects unavailable.

Map and network requests

The site is hosted by GitHub Pages. When your browser requests the site, GitHub and the network providers involved may process technical request information such as your IP address, browser, and requested files under their own policies. See GitHub's privacy statement.

When you open the terrain map, the browser requests map imagery from the U.S. Geological Survey and elevation tiles from AWS Terrain Tiles. Those services receive the network requests needed to return the map tiles, which can reveal the geographic area being viewed along with ordinary request metadata. See the USGS privacy policy and AWS privacy notice.

The optional Mapped features control is off until you enable it. If enabled, the app sends the visible map bounds—not your full saved project—to the public OpenStreetMap Overpass API to request nearby mapped features. The bounds identify the small area currently displayed. See the OpenStreetMap Foundation privacy policy.

The app does not request device geolocation. It uses map coordinates that you select or provide through an import or map link. Map and public-data coverage can be incomplete or inaccurate.

Public project exports

The separate public-export feature creates a project JSON file intended to be placed beside the site files on its host. If you do that, the file and its contents become available to people who can reach the published site. A view-only link is not access control. Check the file for names, coordinates, parcel details, notes, and other information you do not want to disclose before publishing.

Accounts, payments, and related services

The current site interface does not offer account sign-in, paid plans, or checkout. No payment link or fundraiser is presented here. However, Stripe webhook code remains in the deployment source and may be active only if separately configured with server-side settings. That configuration and any related provider records or logs have not been audited for this notice. The operator should verify the hosting configuration before making claims about whether Stripe or Supabase process any information.

Analytics, advertising, and contact

The application source does not include a configured analytics or advertising script. This statement does not cover technical logs maintained by the site host or services listed above. This prototype currently does not publish a verified business identity or dedicated privacy-contact address. Do not submit sensitive information or expect this prototype to provide a formal data-request process.

Questions and future changes

This notice may need substantial revision before commercial use, especially if accounts, payments, analytics, cloud storage, support forms, or other data collection are added. A commercially launched service should identify its operator and provide an appropriate contact channel and complete, jurisdiction-aware privacy disclosures.
